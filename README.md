# ПапЛови — сайт детского бассейна

Статический одностраничный сайт для **ПапЛови** (Екатеринбург, ул. Черничная, 55): грудничковое и детское плавание.

## Локальный просмотр

Откройте `index.html` в браузере или поднимите простой сервер:

```bash
# Python
python -m http.server 8080

# Node
npx serve .
```

Сайт: http://localhost:8080

## Структура

- `index.html` — страница
- `css/styles.css` — стили
- `js/main.js` — подбор формата + форма заявки
- `assets/img/` — фото из VK сообщества

## Заявки

Форма не шлёт на бэкенд: открывает **Telegram** / **WhatsApp** с предзаполненным текстом (или `tel:`).

Контакты по умолчанию:
- Телефон: `+7 (922) 026-52-94`
- Telegram: https://t.me/Paplovi

Поменяйте номера/ссылки в `js/main.js` и в `index.html`.

## GitHub Pages

Репозиторий настроен на публикацию из ветки `main` (корень). После пуша:

1. Settings → Pages → Source: **Deploy from a branch** → `main` / `/ (root)`
2. Дождитесь деплоя, откройте URL вида `https://<user>.github.io/paplovi/`

Если сайт лежит в **project pages** (не user/org site), обновите пути в `robots.txt`, `sitemap.xml` и `canonical` / Open Graph в `index.html` на реальный URL.

Для корректных относительных ассетов на project pages всё уже относительное (`css/…`, `assets/…`).
